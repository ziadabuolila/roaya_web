# Roaya Pay — Next.js Website

موقع عربي RTL لشركة رؤية باي لحلول السداد والبرمجيات، مبني باستخدام Next.js App Router وTypeScript وCSS ومكتبة Lucide.

## التشغيل

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. لبناء نسخة الإنتاج: `npm run build` ثم `npm start`.

## الصفحات

- `/` الرئيسية
- `/about` عن الشركة
- `/team` إدارة الشركة
- `/developers` المطورين
- `/services` الخدمات
- `/partners` الشركاء
- `/fag` الأسئلة الشائعة
- `/contactUs` تواصل معنا

## المزايا

- تصميم Neo-Fintech بهوية خضراء وخلفيات متدرجة هادئة ورسوم CSS/SVG-like مبنية بالكود.
- تخطيط متجاوب للشاشات الصغيرة والكبيرة، وقائمة موبايل.
- وضع فاتح وداكن مع حفظ الاختيار محليًا في المتصفح.
- تأثيرات دخول عند التمرير، مؤشر تقدم للقراءة، وحركات عائمة مع احترام `prefers-reduced-motion`.
- Metadata عامة وبيانات Open Graph، ونموذج تواصل يجهز رسالة بريد إلى `roya.tech2025@gmail.com`.
- محتوى الشركاء والإدارة لا يختلق أسماء أو شعارات؛ تضاف البيانات المعتمدة عند توفيرها.

## ملاحظات قبل النشر

- نموذج التواصل يفتح تطبيق البريد برسالة جاهزة؛ لا يرسل البيانات إلى خادم من تلقاء نفسه. لإرسال الطلبات مباشرةً يلزم ربط API أو خدمة بريد موثوقة مع حماية مناسبة.
- أضف ملف الشعار الرسمي والصور المعتمدة للشركة والإدارة والشركاء قبل النشر النهائي.
- لم تُضمّن بيانات اعتماد أو مفاتيح API.
